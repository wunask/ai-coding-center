Secure remote agent access

Claude Code

Connect to Ubuntu over a private SSH connection, then run:

tmux new -s claude
fcc-claude

Detach with Ctrl+B then D. Reattach later with tmux attach -t claude. A mobile SSH client can use the same private connection.

Codex

FCC has built-in browser Code Sessions. Use its supported local/private access; do not publicly reverse-proxy the localhost-only Admin UI. The standalone dashboard does not launch Codex sessions.

Security

Protect any published dashboard hostname with Cloudflare Access (email OTP), and do not expose SSH, FCC Admin, or terminal services to the public internet.
